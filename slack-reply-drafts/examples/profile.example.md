# Profile: #project-updates (example)

This is an invented example of the `profile.md` the skill writes beside each
conversation's messages. Every name, message and timestamp here is made up.
Real profiles are private and stay in the data directory.

## Evidence

- Sample: 42 messages by the user over 30 days, most of them one or two sentences.
- Uncertainty: only 3 examples of disagreement, so that section is tentative.

## Explicit rules

Standing rules given by the user. They override anything observed below.

- No emojis or text smileys.
- No em dashes. Use a comma, a period or a colon.
- Do not copy typos from older messages.

## Observed style

- **Tone:** direct and even. States the answer first, then the reason.
- **Length:** one to two short sentences. Longer only when listing steps.
- **Greeting:** none inside an active exchange. First name only when opening a new thread.
- **Acknowledgement:** a short "Got it" or "Makes sense" before the answer, and only when the other person shared new information.
- **Disagreement:** says what would not work and offers one alternative. No softening phrases.
- **Questions:** one question per message, phrased so it can be answered in a word.
- **Updates:** what changed, then what is next. No status adjectives.
